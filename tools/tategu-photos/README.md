# 対馬 建具・採寸（現場用ミニアプリ）

iPhone の Safari で、建具の写真と寸法・材質を番号ごとに残すアプリです。

公開想定URL（Pages 有効化後）:

`https://hirotarou0712-arch.github.io/tushima-kominka-PJ/tools/tategu-photos/`

## 合言葉

起動時に合言葉が必要です（チャットで共有。README には書きません）。  
一度正解した端末では次回から聞きません。一覧下の「合言葉ロックに戻す」で再ロックできます。

通りすがりの人が URL を開いただけでは先に進めません。ソースを読めば破れる可能性がある簡易門です。写真や採寸は端末の中だけです。

## 使い方（リスト型）

平面図は使いません。現場で番号を追加しながら記録します。

1. **通信できる場所で一度 URL を開く**（「オフライン準備完了」が出るまで待つ）
2. Safari の共有 → **ホーム画面に追加**
3. 対馬ではホーム画面のアイコンから開く
4. 「窓を追加」または「ドアを追加」で番号を振る（窓は `W01`…、ドアは `D01`…）
5. 各番号ごとに: 写真（複数可）→ 縦・横 → 素材 →（窓のみ）床からの高さ → 任意メモ
6. 「ZIPを書き出す」→ 保存先を Files などで選ぶ

## 入力項目

| 項目 | 備考 |
|---|---|
| 写真 | 1建具あたり複数枚 |
| 縦 / 横 | cm |
| 素材 | ガラス・障子・襖・木製扉・アルミサッシ・不明・その他 |
| 床からの高さ | 窓のみ（cm） |
| メモ | 任意（例: 玄関南・引き戸） |

## 注意

- **旧版（地図あり）からの更新**: 初回起動時に端末内データを空にしてリスト版へ移行します。旧データが必要な場合は、更新前に ZIP バックアップを取ってください
- カメラロールに必ず残る保証はありません。正本はアプリ内です
- ZIP の「書き出しました」は保存成功の断言ではありません。保存画面で保存してください
- 途中でも ZIP バックアップを推奨します

## ZIP の中身

- `{番号}/{番号}_001.jpg` … 写真
- `建具.csv` … 番号・種類・寸法・素材・枚数・メモ
- `data.json` … 機械用の生データ

## ローカル確認

```bash
cd tools/tategu-photos
python3 -m http.server 8080
```

`http://127.0.0.1:8080/` を開く。
