# 届出添付書類（叩き台）

長崎県生活衛生課（2026-08-24）確認に基づき、小島名義届出に必要な2書類の叩き台です。

| ファイル | 用途 |
|---|---|
| `01_賃貸借契約書.html` / `.pdf` | 父（賃貸人）と小島（賃借人）の間の賃貸関係を示す控え |
| `02_住宅宿泊事業_承諾書.html` / `.pdf` | 父が所有物件での民泊を承諾していることを示す書面 |

## 使い方

1. ブラウザで HTML を開く
2. `【】` や空欄を埋める
3. 印刷 → PDF保存、または紙に印刷して署名・押印
4. 届出時は写し／スキャンを添付

## 参考にした雛型

- 茨城県「住宅宿泊事業の用に供する承諾書」様式
- 国土交通省「賃貸住宅標準契約書」および転貸承諾の考え方
- 長崎県回答: **指定フォーマットなし。内容が分かればOK**

## 注意

- 家族間でも、賃貸の事実と民泊承諾の意思が書面で分かることが重要
- 賃料は実額で記入する（名目でもよいが、空欄は避ける）
- 届出提出用の全部事項証明書は **届出日前3か月以内** のものが必要なので、父手元の証明書が古い場合は直前に取り直す
