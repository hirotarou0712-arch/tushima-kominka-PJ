## 1. 一言でいうと

```
① 届出者の名義を確定（県）
② 登記・居住証明など「事実」を固める
③ 図面（消防用＋県届出用）→ 消防で設備確定
④ 設備・安全措置・防炎 → 消防法令適合通知書
⑤ 管理業者契約・周辺周知・様式A/B/C
⑥ 官公署書類を届出日前3か月以内で取り直し
⑦ 民泊制度運営システムで届出 → 受理（目安2週間＋不備）
⑧ 標識掲示・名簿・本人確認・案内文 → 営業開始
⑨ 偶数月の定期報告・180日管理（継続）
```

消防の適合通知があっても、**県の届出が通らなければ営業できません。**  
「システムから申請する」段階で慌てないよう、**§8 の届出前チェックを先に全部埋める。**

## 4. 「住宅の登記事項証明書」とは

法務局が発行する建物の公的証明書（旧称: 登記簿謄本）。  
所在（地番）、家屋番号、構造、**床面積**、所有者名などが載る。

- 県届出に **必須**（システム入力の不動産番号／地番などの根拠にもなる）
- **取り方（今回確定）**
  1. **地番を特定する**（対馬支局に電話／父の固定資産税通知書・権利証）
  2. 地番を持って **福岡法務局本局**で全部事項を請求
- 家屋番号は、福岡の回答では **必須ではない**
- 提出用は **全部事項**。**届出直前（3か月以内）に取り直す**前提で動く

窓口:
- [福岡法務局・本局](https://houmukyoku.moj.go.jp/fukuoka/table/shikyokutou/all/honkyoku.html)（中央区舞鶴3-5-25）証明書窓口 `092-722-4725`

## 5.5 現地スケジュール（前提）

前提（2026-08-24時点）:

- **お盆:** 2026-08-13〜15 の現地で、採寸・建具確認・写真整理の土台は完了
- **直近目標:** できれば **9月中に民泊申請のOKを取る**
- **見積の順番:** OK が取れ次第、**給湯の電気工事見積**を取得
- **購入判断:** 見積で残予算を見たうえで、家具・家電を買い揃える
- **次の現地:** **2026-12-05〜12-08（3泊4日）** に父母と3人で対馬へ行き、現地でやることをすべて終える

方針: 8月までで **「測る・撮る・消防相談用の材料を固める」** は終えた。9月は申請判断、10〜11月は遠隔段取り、現地の力仕事は12月に集約する。

### お盆（8/13–15）でやること ← ここまでやれば秋まで遠隔で進められる

優先度順。3日・暑さ前提で、屋外の短時間作業と父との確認が中心。

| 優先 | やること | なぜお盆で必要か |
|---|---|---|
| 必須 | **正確な住所・地番の特定**（父＋通知書／対馬支局） | 登記が取れないと面積も名義も確定しない |
| 必須 | **登記事項証明書**（対馬支局で取るか、地番だけ取って福岡で可） | 県・図面の土台 |
| 必須 | **父と届出名義の方針を話す**（所有者／賃借＋承諾） | 県確認・書類の分岐が決まる |
| 必須 | **平面図の正確採寸**（メジャー・cm） | 消防が設備判定できない。自作OKは確認済み |
| 必須 | **外周の建具写真＋寸法**（窓・扉、床からの高さ、ガラス種類） | 消防提出の建具表用 |
| 必須 | **台所・浴室・便所・洗面の現況写真** | 「住宅」の4設備。風呂後回し可否の判断材料 |
| 必須 | **既存の消防設備の有無を写真**（警報器・消火器など） | 見積・消防相談の材料 |
| 推奨 | **居住証明の種を残す**（現地の買い物レシート、船／交通の領収書） | 要件Cの添付用。帰省のたびに積む |
| 推奨 | **近隣の顔ぶれをざっと把握**（誰が隣か。周知はまだ配らないでよい） | 秋〜届出前の様式A用 |
| 任意 | 消防署へ顔出し／図面提出タイミングの相談 | 測り終えてからでも可（福岡帰宅後メールでも可） |
| 任意 | 管理業者・設備業者の **電話の当たり**だけ（契約はしない） | 秋に本交渉 |

### お盆でやらないこと（秋 10–11月へ送る）

- 荷物の大片付け・廃棄・不用品業者
- 本格的な業者手配・工事日程の確定
- 消防設備の設置工事（図面提出→必要設備確定のあと）
- 周辺住民への正式な事前周知チラシ配布（届出が近づいてからでよい）
- 家具購入・風呂・屋根などの大型投資（原則は届出受理後）

### 12月5日–8日（3泊4日）でやること

現地でやる作業は、この4日間で完了させる前提。

- 荷物整理・移動・処分（業者立会い）
- すぐ使うものは納戸、長期保管は小屋へ移動
- 不用品はその場で処分判断
- 家具・家電の搬入、設置、民泊レイアウトの仕上げ
- 現地確認が必要な残作業の完了

### 届出と別枠（受理後でもよい投資）※ただし注意

## 7. 迷ったときの判断ルール

1. **先に「誰が届出者か」** → 名義が固まらないと書類が全部空振り
2. **次に登記・居住要件・4設備** → 事実関係
3. **面積に合わせて図面** → 消防へ（設備は確定してから購入・工事）
4. **管理業者は「対馬10分」で先に当たりをつける**（島だと業者が最大ボトルネック）
5. **様式A/B/C・身分証明書・3か月ルールは送信直前に足りなくなりやすい** → §8で先回り
6. 消防と県は別ゲート。**両方通って初めて営業可**
7. 送信＝営業可ではない。**受理＋標識掲示まで**が開始条件
